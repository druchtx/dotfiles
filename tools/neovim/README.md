## 工作原则

- 添加插件前，先理解对应的 Neovim 原生能力。
- 每次只增加一个可以独立验证的能力。
- 记录每个插件存在的理由、职责和依赖。
- 同一种能力只保留一个主要实现。
- 每完成一个学习或实装阶段，单独提交一次。
